

# SubTitleSearcher
Subtitle search and query tool (Java version). Supports subtitle searching for 4K (2160p), 1080p, and 720p videos. Integrates search APIs from Zimuku, Thunder, Shooter, and SubHD.

**Go Version:**  
https://gitee.com/andyfoo/GoSubTitleSearcher  
https://github.com/Andyfoo/GoSubTitleSearcher  

**This is the Java version. It will no longer be updated:**  
https://gitee.com/andyfoo/SubTitleSearcher  
https://github.com/Andyfoo/SubTitleSearcher  


You can drag and drop a video file or select a video to start searching for subtitles.
![You can drag and drop a video file or select a video to start searching for subtitles](https://raw.githubusercontent.com/Andyfoo/SubTitleSearcher/master/docs/screenshot/p1.png)

You can download subtitles individually or in batch, and copy the title text.
![You can download subtitles individually or in batch, and copy the title text](https://raw.githubusercontent.com/Andyfoo/SubTitleSearcher/master/docs/screenshot/p2.png)
